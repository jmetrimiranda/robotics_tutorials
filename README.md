# Livro de Robótica

Livro de estudo construído com [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Rodar localmente
```bash
pip install mkdocs-material
mkdocs serve        # abre em http://127.0.0.1:8000
```

## Publicar
Basta dar push na branch `main` — o GitHub Actions publica no GitHub Pages automaticamente
(ative em Settings > Pages > Branch: gh-pages).
